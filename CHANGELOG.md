# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-02-12

### Added
- Initial project scaffolding
- Monorepo structure with Turborepo
- Backend API with Express, TypeScript, and Prisma
- Frontend web app with Vite, React, and TypeScript
- Shared types package
- Canvas-based design editor using Konva
- Support for rectangles, circles, triangles, text, and images
- Element manipulation (drag, resize, rotate)
- Properties panel for editing elements
- Design save/load functionality
- Image upload support
- PNG export functionality
- PostgreSQL database with Prisma ORM
- Local file storage (with S3-ready abstraction)
- CORS and rate limiting middleware
- Docker Compose for PostgreSQL
- Comprehensive documentation
