# Web

Frontend web application for Canva Litmus Clone.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run in development:
   ```bash
   npm run dev
   ```

The app will be available at http://localhost:5173

## Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## Features

- Design list view with create/delete functionality
- Canvas-based design editor with Konva
- Add shapes (rectangle, circle, triangle)
- Add and edit text
- Upload and add images
- Drag, resize, and rotate elements
- Properties panel for element editing
- Save and export designs to PNG
